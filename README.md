# Danish Mushtaq — Portfolio Revamp

A complete vanilla HTML/CSS/JavaScript redesign of the original portfolio.

## Structure

- `index.html` — semantic page structure and project data
- `app.css` — responsive visual system and layout
- `app.js` — mobile navigation, scroll reveal, active navigation and form feedback
- `Project Images/` — original portfolio images, resume and icons retained from the source project

## Deploy

This is a static site. Upload the folder directly to Netlify, GitHub Pages, or any static hosting provider.

No build step or npm installation is required.
